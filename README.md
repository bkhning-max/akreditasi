# SATU AURA - UIN Sayyid Ali Rahmatullah Tulungagung

**SATU AURA** (*Accreditation Update & Risk Alert System*) adalah sistem monitoring dan peringatan dini akreditasi program studi di lingkungan UIN Sayyid Ali Rahmatullah Tulungagung.

## 📁 Struktur Repositori
- `index.html` : Halaman utama antarmuka (Dashboard & Visualisasi).
- `data.csv` : Berkas data utama seluruh status akreditasi program studi.
- `README.md` : Dokumentasi repositori.

## 🚀 Cara Memperbarui Data Akreditasi
1. Edit atau timpa berkas `data.csv` di repositori ini.
2. Lakukan **Commit changes**.
3. Website di GitHub Pages akan otomatis memperbarui tampilan dashboard dan data tabel tanpa perlu mengubah kode `index.html`.
